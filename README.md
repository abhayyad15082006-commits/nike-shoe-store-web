# 👟 Nike Shoe Store Web Application

A modern, responsive e-commerce web application inspired by Nike, featuring an interactive shopping experience, dynamic product filtering, and a sleek glassmorphic UI.

## 🚀 Features
- **Dynamic Product Catalog:** Filter shoes by category (Running, Lifestyle, Basketball).
- **Live Search Bar:** Instantly search through products by name, description, or category.
- **Interactive Customizer:** Switch product angles and build custom editions.
- **Shopping Cart System:** Add items, adjust quantities, view subtotals, and simulate checkouts.
- **Wishlist & User Auth:** Interactive wishlist counter and modal sign-in UI.
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS**
- **Vanilla JavaScript (ES6)**
- **FontAwesome Icons**
